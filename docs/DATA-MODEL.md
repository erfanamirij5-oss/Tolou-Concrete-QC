# مدل داده مقدماتی و مرحله جاری

## مسیرهای ثبت
مشتری ← پروژه ← نوبت بتن‌ریزی ← سری نمونه‌برداری ← نمونه ← آزمون.
آزمایش داخلی ← سری نمونه‌برداری ← نمونه ← آزمون؛ پروژه مشتری اجباری نیست و در این مسیر نگهداری نمی‌شود.
عنوان، هدف، نمونه‌بردار و ثبت‌کننده برای آزمایش داخلی لازم‌اند. نمونه‌بردار و ثبت‌کننده مستقل‌اند.

## قواعد ذخیره‌سازی هدف
- شناسه‌های پایدار برای شرکت، مشتری، پروژه، بتن‌ریزی، سری، نمونه و نتیجه.
- منشأ بتن و آزمایشگاه آزمون مستقل؛ نتیجه خارجی با پیوست و شناسه رویداد متناظر.
- نسخه طرح مخلوط تغییرناپذیر پس از ارتباط با نمونه؛ اصلاح با نسخه جدید.
- نتیجه دارای بازنگری و وضعیت پیش‌نویس/تأیید/ابطال؛ مقدار قبلی و علت تغییر حفظ شود.
- کلید خارجی مرکب یا کنترل تراکنشی برای جلوگیری از ارتباط پروژه/بتن‌ریزی متعلق به شرکت دیگر.
- اعتبارسنجی فعلی فقط شکل ورودی را کنترل می‌کند؛ بررسی وجود شناسه و مالکیت باید در سرویس پایگاه داده انجام شود.

## واحدهای بچ داخلی
مبنای طرح مرجع kg/m³ و حجم هدف L است. مقدار برنامه‌ریزی‌شده kg = مقدار مرجع × حجم هدف / ۱۰۰۰.
این تبدیل صرفاً مقیاس‌کردن حجم هدف است، نه اندازه‌گیری بازده واقعی یا تصحیح آب مؤثر.
actualKg تا ثبت مقدار واقعی null می‌ماند. مقدار گمشده صفر نیست. محاسبات بدون گردکردن زودهنگام و نمایش با دقت مصوب انجام شوند.
